# AI-VERDE Docs

Documentation site for AI-VERDE, built with [Zensical](https://zensical.org).

## Setup

```bash
pip install -r requirements.txt
```

## Development

```bash
zensical serve
```

Opens a live-reloading server at `http://localhost:8000`.

## Build

```bash
zensical build
```

Output is written to `site/`.
