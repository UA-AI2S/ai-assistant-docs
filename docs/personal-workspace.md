# Your Personal Workspace

Every user gets a personal workspace when they sign in to AI Assistant. This is separate from any shared workspaces your instructor or team lead may have added you to.

## What's in Your Personal Workspace

Your personal workspace gives you:

- **Your own budget** — A usage allowance independent of any shared workspace. The dashboard shows how much you've used and how much remains.
- **Default models** — A set of models available to all users. These may differ from the models in a shared workspace.
- **An API key** — Just like a shared workspace, you can copy your personal API key and use it with external tools.

## Personal vs. Shared Workspaces

|                | Personal Workspace             | Shared Workspace                                  |
| -------------- | ------------------------------ | ------------------------------------------------- |
| **Created by** | Automatically on first sign-in | System admins, on an instructor's request         |
| **Members**    | Just you                       | You and other workspace members                   |
| **Models**     | Platform defaults              | Configured by the workspace admin                 |
| **Budget**     | Individual allowance           | Shared pool; workspace admins set member limits   |
| **API key**    | Your own                       | Your own (but usage draws from the shared budget) |
