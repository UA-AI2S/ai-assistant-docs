# Overview for Instructors

As a workspace admin, you manage how your workspace interacts with AI Assistant. This page covers what you can do and how to get set up.

## What You Can Do

| Capability           | Description                                                                                             |
| -------------------- | ------------------------------------------------------------------------------------------------------- |
| **Manage members**   | Add and remove members individually or in bulk via CSV. Assign admin or member roles.                   |
| **Configure models** | Control which LLMs are available to your workspace. Bring your own model if needed.                     |
| **Set budgets**      | View total workspace spend, set a default per-member limit, or customize limits for individual members. |
| **Monitor usage**    | See per-member usage breakdowns on the Budget page.                                                     |
| **API keys**         | Each member gets their own key. Admins can view and regenerate member keys.                             |

For details on all of these, see [Managing a Workspace](settings.md).

## Setting Up a New Workspace

To request a new workspace for your course, lab, or team:

1. Fill out the [workspace request form](https://docs.google.com/forms/d/e/1FAIpQLSdWX9Nf9gsJ4vJ9r1FBIrW61QE60T9tl6uEbxFjTut3mUATEg/viewform){target=\_new}.
2. The AI2S team will create your workspace and contact you once it's ready.
3. Your workspace will appear on your dashboard at [ai-assistant.responsibleai.arizona.edu](https://ai-assistant.responsibleai.arizona.edu/).

You can also find the request form by visiting [ai-assistant.responsibleai.arizona.edu](https://ai-assistant.responsibleai.arizona.edu/) and clicking **Get Access**.

## Support

If you need help or want to request a model, budget adjustment, or BYO LLM setup, contact **ai-assistant-support@list.arizona.edu**.
